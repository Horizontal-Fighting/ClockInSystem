# 录音执行单（照着念就行）

配套 `samples.csv`（脚本用）与本单（人用）。**录音时看这份，跑脚本时不用管它。**

---

## 一、录音前准备

| 项 | 要求 |
|---|---|
| 设备 | **用家长手机录**，不要用电脑麦克风（电脑麦太灵敏，结果会偏乐观，测不准真实场景） |
| 环境 | 安静房间，关电视。手机放孩子面前 **20-30cm** |
| 格式 | 手机自带录音机即可。一次录一条，别连录 |
| 命名 | **每条录完立刻改名为编号**，例如第一条改成 `A01.m4a` |

> ⚠️ 命名是唯一容易乱的地方。建议录一条、停、改名、再录下一条。
> iOS 录音默认是 m4a，安卓可能是 mp3/amr——**都行**，转码命令统一处理。
> 如果是微信语音导出的 amr/silk，先发给文件传输助手再用其他 App 转一次，脚本不认这两种格式。

## 四、录完之后

### 1. 音频放进 spike 目录

把所有 `A01.m4a` … `D06.m4a` 拷进 `D:\WorkBuddy\ClockIn‌System\spike\`（和 `run_eval.py` 同级）。

### 2. 一键转码 + 自动验证（Git Bash 里跑）

```bash
cd "D:/WorkBuddy/ClockIn‌System/spike"
PY="C:/Users/Horiz/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
"$PY" transcode.py
```

脚本自动做三件事：转码 → 逐条验证 `16000Hz / mono / 16bit` → 对照清单告诉你**还缺哪几条**。
原始录音自动备份到 `raw_audio/` 文件夹。

> 不用再手动敲 ffmpeg 命令、也不用 ffprobe——验证已内置在脚本里，看到 `✓` 才算过。

### 3. 跑评测

```bash
PY="C:/Users/Horiz/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
"$PY" run_eval.py --limit 1     # 先跑 1 条确认通
"$PY" run_eval.py               # 全量（约 10 分钟，不到 1 元）
```
